# 🎨 K72 – A Modern Creative Agency Website

**K72** is a visually immersive, animation-rich creative agency website built with **React**, **GSAP**, and **ScrollTrigger**.  
It blends high-end design with modern web motion principles to deliver a smooth, cinematic experience inspired by professional digital studios.

---

## 🚀 Features

- 🌀 **GSAP Animations** – Beautiful, high-performance motion effects  
- ⚙️ **ScrollTrigger** – Scroll-based transitions and interactions    
- ⚛️ **Modular React Architecture** – Reusable, maintainable components  
- 🎨 **Tailwind CSS Styling** – Fast, scalable utility-first design system  
- ⚡ **Optimized Performance** – Smooth animations with minimal reflows  

---

## 🛠️ Tech Stack

| Category | Tools Used |
